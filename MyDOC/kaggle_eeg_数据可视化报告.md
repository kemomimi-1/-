## 6. 困惑检测核心机理

当学生处于**困惑状态**时，脑电波会呈现以下特征模式：

```
困惑时的脑电信号模式:
┌──────────────────────────────────────────────────┐
│  Theta ↑ (信息处理受阻，工作记忆超载)              │
│  Alpha ↓ (无法进入轻松理解的状态)                  │
│  Beta  ↑ (大脑拼命努力思考但未成功)                │
│  Attention ↓ (注意力分散/涣散)                     │
│                                                    │
│  → Theta/Beta 比值 ↑ (核心困惑指标)                │
│  → Theta/Alpha 比值 ↑ (认知负荷指标)               │
│  → Engagement 指数 ↓ (参与度下降)                  │
└──────────────────────────────────────────────────┘
```

我们的 V9 引擎通过 **112 维特征工程**捕捉这些模式：
- 原始 10 频段 → 6 种认知比值 = **16 维基础特征**
- × 7 种时序变换（原始值 + 一阶差分 + 二阶差分 + 短窗均值 + 长窗均值 + 短窗方差 + 长窗方差）
- = **112 维高阶时序特征空间**

然后交由 XGBoost (300 棵树, GPU CUDA 加速) 进行 Subject-Dependent 5-Fold 交叉验证分类。
